# Список задач — тестовое задание ZalogHub

Простой todo-список на **React + TypeScript**, собранный на **Vite**. Без сторонних библиотек и сервера.

## Возможности

- Добавление задачи через поле ввода и кнопку (или Enter)
- Пустую задачу или задачу из одних пробелов добавить нельзя — кнопка неактивна, ввод обрезается по краям
- Переключение задачи между выполненной и невыполненной (чекбокс)
- Выполненные задачи визуально отличаются: зачёркнутый приглушённый текст
- Удаление задачи
- Фильтрация: все / активные / выполненные
- Сохранение в `localStorage` — задачи остаются после обновления страницы
- Счётчик активных задач и кнопка «Очистить выполненные»
- Адаптивная вёрстка и тёмная тема по системной настройке

## Запуск

Нужен Node.js 20.19+ (или 22.12+).

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Сборка продакшен-версии:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  App.tsx                  — корневой компонент, фильтрация и счётчики
  types.ts                 — типы Todo и Filter
  hooks/useTodos.ts        — состояние задач и синхронизация с localStorage
  components/
    TodoForm.tsx           — поле ввода и кнопка добавления
    TodoItem.tsx           — строка задачи: чекбокс, текст, удаление
    FilterBar.tsx          — переключатель фильтров
```

## Затраченное время

Примерно 50 минут.
